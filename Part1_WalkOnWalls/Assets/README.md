# Part 1 — Art references

## `astronaut-mascot-styleframe.png`

The series mascot style frame, generated on Comfy Cloud (Flux 2 Pro) from the
Appendix A art direction in `../Scripts/Custom-Gravity-Part1-Script.md`.

Proportions are deliberately **realistic adult (~7 heads tall)**, not chibi, so
the mascot reads as the same body as the UE5 Mannequin in the screen-capture
footage. An earlier 4-heads-tall version was rejected for that reason.

This is a **style reference**, not a production asset — the Remotion mograph
builds the astronaut from three.js geometry. Use this frame for palette,
material, rim-light and bloom decisions.

Pose is a relaxed A-pose, which also makes it a usable plate if the mascot is
ever converted to a mesh (e.g. via the `api_tripo_multiview_to_model` workflow).
